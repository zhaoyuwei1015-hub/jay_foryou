# 周杰伦星球 · jay_foryou

远程仓库：https://github.com/zhaoyuwei1015-hub/jay_foryou

一个周杰伦主题的全栈网站：作品库、相册、实时新闻、收藏点赞评论，外加一个叫"阿 chou"的 AI 助手，
以及给管理员用的内容后台。

## 技术栈

- 前端：Vue 3 + Vite + Vue Router + Pinia + Element Plus
- 后端：Spring Boot 3 + Java 17 + Spring Security + JWT + MyBatis-Plus
- 数据库：MySQL 8，缓存 Redis
- AI：待定（不使用 Ollama；后期可能尝试扣子 Coze）

## 目录结构（规划的）

```
backend\    后端（Spring Boot）
frontend\   前端（Vue 3）
docs\       架构图、设计文档、学习笔记
work\       临时试验，不进 git
```

## 怎么开始

1. 读 `PROGRESS.md`，看现在走到哪一步了
2. 读 `AGENTS.md`，这里写了这个项目的工作方式和约定
