开发阶段路线

阶段做什么主要学到
0建仓库、定规范、进度单Git、工程规范
1后端起服务，第一个接口Spring Boot、Maven
2建库建表，连数据库做增删改查SQL、MyBatis-Plus
3分层 + 统一返回 + 全局异常 + 日志工程分层
4前端起项目，页面调到后端数据Vue 3、Vite、Axios
5第一个完整业务：列表 + 分页 + 详情前后端联调
6注册登录、密码加密、JWT、角色权限Spring Security
7收藏 / 点赞 / 评论 + RedisRedis、并发
8头像与图集上传文件上传
9管理后台 + 数据看板CRUD 抽象、权限
10阿 chou：接入本地大模型、流式回答SSE、提示词
11测试、接口文档、JVM 调优、部署JUnit、JVM、Nginx
